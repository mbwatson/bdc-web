# What content lives here?

This directory is for content. Not all content, just
structured content collections defined in
[`src/content.config.ts`](../content.config.ts):

- Meetings (quarterly + bi-annual, with materials)
- RFCs
- Working groups
- Members directory
- Recurring meetings

Anything listable, filterable, or schema-validated belongs
here. One-off marketing pages and free-form layouts belong
in `src/pages/` instead.
