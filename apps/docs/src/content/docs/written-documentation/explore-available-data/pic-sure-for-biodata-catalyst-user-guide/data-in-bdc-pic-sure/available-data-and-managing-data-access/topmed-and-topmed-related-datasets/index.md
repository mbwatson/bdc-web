# TOPMed and TOPMed Related Datasets

The BDC ecosystem hosts several datasets from the NHLBI Trans-Omics for Precision Medicine (TOPMed) program. The _BDC-PIC-SURE_ platform has integrated the clinical and genomic data from all studies listed in the **Data Dashboard**, which can be accessed here: [https://picsure.biodatacatalyst.nhlbi.nih.gov/dashboard](https://picsure.biodatacatalyst.nhlbi.nih.gov/dashboardhttps://picsure.biodatacatalyst.nhlbi.nih.gov/dashboard) &#x20;

{% hint style="info" %}
Through the ingestion process, occasionally, BDC-PIC-SURE will ingest phenotypic data for the TOPMed studies before genomic data.
{% endhint %}
