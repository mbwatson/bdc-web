# Publicly Available Datasets

_BDC-PIC-SURE_ hosts several publicly available datasets. This means that no authorization is required to access this participant-level data. This participant-level data can be accessed on the Explore page for authorized cohort building after logging in.

For a complete list of publicly available datasets, please refer to the Data Dashboard: [https://picsure.biodatacatalyst.nhlbi.nih.gov/dashboard](https://picsure.biodatacatalyst.nhlbi.nih.gov/dashboard)
