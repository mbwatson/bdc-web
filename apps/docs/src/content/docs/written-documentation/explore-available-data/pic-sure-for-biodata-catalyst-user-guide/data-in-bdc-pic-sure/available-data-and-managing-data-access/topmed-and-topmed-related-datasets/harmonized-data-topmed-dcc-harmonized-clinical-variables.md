# Harmonized Data (TOPMed DCC Harmonized Clinical Variables)

There are limited amounts of harmonized data available at this time. The TOPMed Data Coordinating Center (DCC) curation team has identified 78 variables that are shared across several NHLBI studies and normalized the participant values for these variables.

The harmonized variables are listed in the table in [Appendix 2](../../../appendix/appendix-2-table-of-topmed-dcc-harmonized-variables-in-pic-sure.md). For more information on this initiative, you can view the additional documentation from the [TOPMed DCC GitHub repository](https://github.com/UW-GAC/topmed-dcc-harmonized-phenotypes) or on the [NHLBI Trans-Omics for Precision Medicine website](https://topmed.nhlbi.nih.gov/dcc-harmonized-phenotypes).

{% hint style="info" %}
The `dcc_harmonization_comments` field in the [TOPMed DCC GitHub repository](https://github.com/UW-GAC/topmed-dcc-harmonized-phenotypes) helps to provide more context to the variables.

For example, the "Body mass index" variable in the TOPMed DCC Harmonized Dataset has a highly implausible maximum value of 348. [The `dcc_harmonization_comments` field of the BMI code](https://github.com/UW-GAC/topmed-dcc-harmonized-phenotypes/blob/master/harmonized-variable-documentation/baseline_common_covariates/bmi_baseline_1.json) explains that the BAGS study had unlikely height and weight measurements for six participants.
{% endhint %}
