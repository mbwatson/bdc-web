# BDC Powered by Terra

To access the Jupyter notebook examples in R and python for the PIC-SURE API, select **View Workspaces** from the [Terra landing page](https://terra.biodatacatalyst.nhlbi.nih.gov/).

Select the **Public** tab and search for "PIC-SURE". Workspaces for the Jupyter Notebook Python and R examples and RStudio examples will be displayed. You must clone the workspaces to edit or run the code within them.

<figure><img src="../../../../../.gitbook/assets/Screenshot 2023-03-28 at 2.32.02 PM.png" alt=""><figcaption><p>Searching for the PIC-SURE API examples in Terra workspaces.</p></figcaption></figure>

Selected data can be handed off to a Terra workspace. For more information about this process, please refer to [PFB Handoff to BioData Catalyst Powered by Terra](../../introduction-to-bdc-pic-sure/explore-authorized-cohort-building/prepare-for-analysis/pfb-handoff-to-biodata-catalyst-powered-by-terra.md).
