# Discover: Publicly Available Cohort Building

The Discover page provides a publicly available search tool that allows users to:

* View studies and datasets that are available in BDC
* Search and filter on variables to build cohorts
* Retrieve obfuscated, aggregate counts
* View variable distributions to learn more about the selected cohort

Discover all data by navigating to [https://picsure.biodatacatalyst.nhlbi.nih.gov/](https://picsure.biodatacatalyst.nhlbi.nih.gov/).
