# Overview of BDC Powered by PIC-SURE

_BDC Powered by PIC-SURE_ is a cohort-building platform that allows researchers to search for terms of interest, apply filters on variables, and retrieve information about the participants that meet the query criteria.

There are two main ways to search and interact with the data: publicly available cohort building on the Discover page and authorized cohort building on the Explore page.

The Discover page enables you to conduct a feasibility study by exploring individual-level data (only aggregate counts are returned) without authorization to access the data. This allows you to search across all studies hosted in BDC. For more information about Discover, please refer to Discover: Publicly Available Cohort Building documentation.

The Explore page allows you to explore participant-level data of publicly available studies and any studies in which they have an active dbGaP Data Access Request (DAR). For more information about this process, please review the Managing Data Access section. From the Explore page, you can also bring participant-level data to a BDC analysis platform to begin your analysis. For more information about Explore, please refer to Explore: Authorized Cohort Building documentation.

{% hint style="info" %}
In September 2024, Open PIC-SURE was moved to "Discover," and Authorized PIC-SURE was moved to "Explore."
{% endhint %}
