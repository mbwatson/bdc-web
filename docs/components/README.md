# Component Standards

```md
> This document is authoritative. If implementation contradicts this guide, update the guide or refactor the code.
````

This directory contains component-level behavior standards for the site.

`docs/components.md` remains the implementation architecture guide (Astro vs React, dependency boundaries, utility-first styling).

- `global-rules.md`: cross-cutting rules for all reusable components
- `button.md`: acceptable use and behavior rules for Button components
- `card.md`: acceptable use and behavior rules for Card components
- `hero.md`: acceptable use and behavior rules for Hero components
- `template.md`: spec template for documenting additional components

When adding a new reusable component standard, create a new file in this directory and link it here.
